# Tomiwa Oladimeji - Portfolio

AI/ML Engineer portfolio built with Next.js and Tailwind CSS.

## 🚀 Quick Start

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open http://localhost:3000

## 📦 Deploy to Vercel (FREE)

1. Push this code to GitHub
2. Go to https://vercel.com
3. Sign in with GitHub
4. Click "New Project"
5. Select your repository
6. Click "Deploy"

Done! Your portfolio is live! 🎉

## ✏️ Adding More Projects

Edit `app/page.js` and add new projects to the `projects` array:
```js
{
  id: 3,
  title: "Your New Project",
  longDescription: "Description...",
  techStack: ["Tech1", "Tech2"],
  github: "https://github.com/username/repo",
  highlights: ["Feature 1", "Feature 2"]
}
```

## 🎨 Customization

- Colors: Edit Tailwind classes in `app/page.js`
- Styles: Modify `app/globals.css`
- Skills: Update the `skills` object in `app/page.js`
